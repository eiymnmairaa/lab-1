
# Cybersecurity: Threats and Vulnerabilities

| No. | Scenario | Category | Reasoning |
|:---:|---|---|---|
| 1 | An employee receives an email from "HR Department" asking them to verify their login details via a link. | Threat | **Phishing** — An external malicious attempt to trick a user into revealing credentials. |
| 2 | A company server is running Windows Server 2012, which no longer receives security updates. | Vulnerability | **Outdated software** — An exploitable weakness due to a lack of security updates. |
| 3 | A developer accidentally uploads API keys to a public GitHub repository. | Vulnerability | **Sensitive information exposure** — Confidential information is exposed due to misconfiguration or human error. |
| 4 | A hacker uses a botnet to flood a website with traffic until it becomes unavailable. | Threat | **DDoS (Distributed Denial of Service)** — An active attack intended to make a website unavailable. |
| 5 | The firewall in a branch office is misconfigured to allow all inbound traffic. | Vulnerability | **Weak configuration** — A security weakness that attackers could exploit. |
| 6 | An insider copies confidential customer data onto a personal USB drive. | Threat | **Insider threat** — An authorized person misuses their access to compromise confidential information. |
| 7 | The organization's password policy allows users to set "12345" as their password. | Vulnerability | **Weak password policy** — Poor access control allows easily guessed passwords. |
| 8 | Cybercriminals send ransomware through email attachments to multiple employees. | Threat | **Ransomware** — A cyberattack designed to encrypt or restrict access to data, often demanding payment. |
| 9 | A company website doesn't validate user input in its contact form, allowing malicious SQL commands. | Vulnerability | **SQL Injection** — A coding flaw that may allow attackers to execute malicious database queries. |
| 10 | Attackers use fake job advertisements on social media to trick users into sharing personal data. | Threat | **Social engineering** — Psychological manipulation used to obtain sensitive information. |
